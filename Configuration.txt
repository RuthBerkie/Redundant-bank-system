for this project, 12 2nd layer switch, 4 3rd layer switch, and 4 routers
the 2nd layer switches will be to the devices and the 3rd layer switches will be connected to the 2nd switches and the routers will be connected to the 3rd layer switches

software used for the project:-MS Visio, visual paradigm (this is used to draw the model), packet tracer for the simulation.

configurations being implemented:
1,basic settings to all devices plus ssh on the routers and 13 switches.
   hostname
   line console and vty passwords
   disable domain ip lookup

2,VLANS assignment plus all access and trunk ports
  create vlans in every department
  vlans(10, 20, 30....)
  each vlan should be a different subnetwork

3,switchport security to all 12 switches
4,subnetting and ip addressing
5,ospf on the routing and 13 switches
6,static ip address to server room devices
7,dhcp server device configuration
8,inter-vlan routing on the 13th switches plus ip dhcp helper address
9,wireless network configuration
10,verifying and testing configuration
